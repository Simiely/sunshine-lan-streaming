# 待机时虚拟屏必须离开桌面拓扑，连接时再交给 Sunshine 拉起

**TL;DR**：虚拟屏装好后不能常驻桌面，也不要用 `DisplaySwitch /internal` 去"藏"它——那会连物理屏一起切走。正确做法是用 Windows CCD 接口只停用虚拟屏那一条 path，物理屏的分辨率、刷新率、相对位置一律不动；Sunshine 连接时用 `ensure_only_display` 重新拉起，断开回滚到这个"已隐藏"的拓扑。

## 为什么

- 虚拟屏常驻桌面会多出一块看不见的显示区域，鼠标能移进去、窗口会跑到上面，用户以为卡了。
- `DisplaySwitch /internal` 是"仅内置屏"语义：台式机没有内置屏时行为不可控，笔记本上则会把外接屏一起关掉，物理屏布局被破坏。
- 隐藏只改 VDD，才谈得上"待机正常、串流时自动出现"。这也是 [虚拟显示器方案](虚拟显示器方案.md) 里"虚拟屏不在桌面拓扑里"的具体实现。

## 怎么做

`scripts\Hide-Vdd.ps1` 走 CCD API，关键参数都有实机依据：

- 查询：`QueryDisplayConfig(QDC_ALL_PATHS | QDC_VIRTUAL_MODE_AWARE)`
- 提交：`SetDisplayConfig(SDC_USE_SUPPLIED | SDC_APPLY | SDC_ALLOW_CHANGES | SDC_SAVE_TO_DATABASE | SDC_VIRTUAL_MODE_AWARE)`
- 被停用的 path 把 `sourceInfo/targetInfo.modeInfoIdx` 置为 `0xFFFFFFFF`（`DISPLAYCONFIG_PATH_MODE_IDX_INVALID`）
- 必须带 `SDC_SAVE_TO_DATABASE`：Sunshine 的 `isApiAccessAvailable` 走 `SDC_VALIDATE | SDC_USE_DATABASE_CURRENT`，数据库当前条目无效时会每 5 秒重试，客户端一直转圈

单屏/多屏是自适应的：脚本只按 `friendly_name` 匹配虚拟屏，物理屏数量只用于保护判断，不参与"该留几块"的决策。

## 断开回滚开关必须显式打开

`ensure_only_display` 只负责连接时切到虚拟屏；断开是否回到隐藏态由 `dd_config_revert_on_disconnect` 决定，Sunshine 2026.516 的缺省值是 `disabled`。不写它时，日志在 `CLIENT DISCONNECTED` 之后没有 `Trying to revert applied display device settings`，桌面会停在虚拟屏仍在拓扑里的状态（2026-11-26 09:04 实测）。虚拟屏基线必须显式写入：

```
dd_config_revert_on_disconnect = enabled
```

v0.6.1 起 `_Baseline.ps1` 的 vdd 配置档已固定包含这一行。

## 两个保护

1. **只剩虚拟屏时先救物理屏**：重装 VDD 时 Windows 可能从显示数据库恢复"仅 VDD"的旧拓扑。脚本检测到物理屏为 0 时，最多 3 次执行 `DisplaySwitch.exe /extend`（每次等 4 秒），恢复后才继续隐藏；仍恢复不了就保持现状并返回 `action=skip`，不会把桌面藏没。
2. **数据库快路径校验**：隐藏后校验 `SDC_VALIDATE | SDC_USE_DATABASE_CURRENT`，失败会自动重新保存一次；同时检查"仅 VDD"拓扑能否通过 `SDC_TOPOLOGY_SUPPLIED` 校验，决定 Sunshine 拉起是走快路径还是回退 best mode。

## 安装途中不要再等 Hide-Vdd 才恢复

设备节点创建时，Windows 会立即按显示数据库套用上一次保存的“仅 VDD”拓扑，物理屏掉线——这是安装阶段黑屏的直接原因。`Install-Vdd.ps1` 现在在 `devcon install` 返回后立刻调用 `Restore-PhysicalLayout`：检测到物理屏少于安装前快照就执行 `DisplaySwitch /extend`（最多 4 次 × 700ms），并在 device_id 复算、DXGI 等待、写基线与隐藏虚拟屏前各复查一次。`Hide-Vdd.ps1` 里 3 × 4 秒的兜底仍然保留，但正常安装流程不会再被触发。

4070S 实测（2026-11-26）：设备创建后物理屏掉线，约 0.7 秒后脚本检测并扩展，再约 0.5 秒两块物理屏恢复，黑屏约 1.2 秒；安装结束位置仍为 `0,0` / `-2560,0`。

## 怎么验证

```powershell
powershell -ExecutionPolicy Bypass -File payload\scripts\Hide-Vdd.ps1
```

看到这行才算通过：

```
SUMMARY mode=multi physical=2 virtual=0 action=hidden
```

再运行一次应输出 `already-hidden`；`-Show` 可以把虚拟屏接回桌面（排障用）。

串流侧验证：连接一次再断开，`sunshine.log` 里应依次出现 `Trying to apply display device settings`、`CLIENT CONNECTED`、`Trying to revert applied display device settings`。4070S 实测 apply 阶段约 0.33 秒，断开回滚后两块物理屏位置与隐藏前一致。

## 边界

- 本脚本只隐藏虚拟屏，不安装驱动、不改 `sunshine.conf`；安装与配置见 `Install-Vdd.ps1`。
- 若断开后物理屏不亮，先跑 `手动工具\恢复显示.cmd`，仍不行再 `Win+P` 选"扩展"或重启。
