# 本机跑通不等于换机可复现：两台实测设备的差异

**TL;DR**：一台是 RTX 4070 SUPER + 2560×1440 的台式机，一台是 AMD 780M + 3200×2000 的笔记本。两台上"合格"的项不是同一批，编码器也不是同一个。任何写死其中一台数值的脚本或判据，换机就会静默失效。

## 已记录设备

| device_id | 机型 | GPU | 驱动 | 活动屏 | 业务网卡 | 编码器 | 验证状态 | 报告 |
|---|---|---|---|---|---|---|---|---|
| `待补` | 4070S 宿主 | RTX 4070 SUPER + UHD 770 | `32.0.16.2114` | 2560×1440@120（2 个活动实例） | `10.4.240.16/23` | `hevc_nvenc` | 真机串流通，局域网拓扑未验证 | [本机基线](reports/2026-11-24-本机基线.md) · [安卓真机](reports/2026-11-24-安卓真机验证.md) |
| `redmibookpro15x` | Redmi Book Pro 15 2023 | AMD Ryzen 7 7840HS / Radeon 780M | `31.0.23013.1023` | 3200×2000（1 个活动输出） | WLAN `192.168.2.179/24` | 未串流，`unknown`（预期 `amf`） | Sunshine `2026.516.143833` 已装，15 项合格；未配对客户端 | [本机基线](reports/2026-11-24-redmibookpro15x-本机基线.md) · [安装验证](reports/2026-11-24-redmibookpro15x-安装验证.md) |

第一台的 `COMPUTERNAME` 没有记录在旧报告里，**不要猜**；补测时按[设备硬件标准](设备硬件标准.md)的规范补上 device_id 后再改这一行。

## 跨机通用与本机专属

| 结论 | 通用？ | 依据 |
|---|---|---|
| `upnp = disabled`、`origin_web_ui_allowed = lan` | 是 | 安全基线，与硬件无关 |
| `POST /api/config` 整体替换会清键 | 是 | 宿主软件行为，与硬件无关 |
| `ensure_only_display` 回滚阻塞 | 是 | 宿主软件行为，换版本仍在 |
| 常驻端口为 47984 / 47989 / 47990 | 是 | 宿主软件行为 |
| 编码器为 `nvenc` | **否** | 4070S 是 NVENC；780M 只能 AMF |
| 锚点分辨率 1920×1080 | **否** | 3200×2000 机器实测安全（与物理屏不同）；物理屏若改成 1080p 就要换锚点 |
| 虚拟屏初始分辨率 800×600 | **否** | 与驱动版本和 EDID 有关，不能写死 |
| `DISPLAYn >= 10` 即虚拟屏 | **否** | 本机实测虚拟屏 52–54、物理屏 1，差距明显；但只是启发式，优先用差集与已记录名 |
| 网卡别名黑名单含 `vgate` | **否** | 第一台有 `vgate0`，第二台也有但地址不同；其它机器未必有 |
| 冲突服务名含向日葵 / RayLink / ToDesk | **否** | 第二台向日葵已停、RayLink 仍在跑 |
| 物理屏数量 | **否** | 第一台 2 个活动实例，第二台 1 个 |

## 加第三台设备时的最小动作

1. 跑 `Get-Baseline.ps1 -Json`，确认输出带 `device_id` 与 `fingerprint`。
2. 按 `<date>-<device_id>-本机基线.md` 归档报告，并在上表加一行。
3. 若默认配置不适用（锚点、网卡、冲突软件、GPU 识别），加一份 `conf/devices/<device_id>.json` 覆盖，**不要改脚本默认值**。
4. 跑一次完整连接—断开循环后再把验证状态从"基线"改成"通过"。

## 怎么验证

```powershell
# 每台机器都应能拿到自己的 ID；若两次输出相同但 UUID 不同，说明是克隆镜像，须改 COMPUTERNAME
powershell -ExecutionPolicy Bypass -File payload\scripts\Get-Baseline.ps1 -Json |
  ConvertFrom-Json | Select-Object device_id, fingerprint
```
