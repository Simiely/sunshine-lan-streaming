# 按需免登录面板

## 为什么需要

Sunshine 的 Web UI 使用 HTTP Basic 认证，每个请求都会重新校验用户名和密码，不发放会话 Cookie（`src/confighttp.cpp` 中 28 处 `authenticate()`）。因此：

- 浏览器无法“登录一次就记住”，重启浏览器后必然重新询问；
- 密码管理器只能保存并预填，是否自动提交受浏览器版本和扩展影响，不可依赖；
- 官方没有关闭认证的配置项，`authenticate()` 在用户名为空时直接拒绝。

## 方案

`payload/scripts/Open-WebUI.ps1` 在 `127.0.0.1` 上起一个很小的转发器：

- 浏览器访问 `http://127.0.0.1:47991/`，代理转发到 `https://127.0.0.1:47990`；
- 自动注入 `Authorization: Basic …`，浏览器侧不需要登录；
- 把 `Origin`、`Referer` 重写为 `https://127.0.0.1:47990`，这是 Sunshine 默认允许的 CSRF 来源；
- 只监听回环地址，不写防火墙规则、不注册服务、不开机自启；
- 空闲 10 分钟无请求自动退出；Sunshine 服务停止也退出；
- 凭据只从 `install-result.json` 读取，不写命令行、不进日志。

`payload/scripts/Panel.ps1` 负责按需启动：已有实例直接打开浏览器，否则隐藏启动代理，等端口就绪后打开默认浏览器。`停止Sunshine面板.cmd` 可立即结束代理。

## 两个一键入口

| 入口 | 内容 |
| --- | --- |
| `一键部署.cmd` | 标准部署：宿主 + 虚拟屏 + 卡片，不安装面板 |
| `一键部署-免登录面板.cmd` | 同上，另加免登录面板：脚本复制到 `C:\ProgramData\sunshine-lan-streaming\panel`，并在公共桌面创建「Sunshine 控制台」快捷方式 |

面板只在双击快捷方式或从图形控制台启动后运行，平时没有常驻进程。实测：代理工作集约 75MB、空闲 CPU 接近 0，只处理 Web UI 的 47990，不经过 Moonlight 的音视频与控制端口。

## 安全边界

- 仅回环可访问；代理运行期间，同机任何程序都能免密访问管理界面；
- 不要把监听地址改成 `0.0.0.0`，也不要为它开放防火墙；
- 空闲自动退出是默认的收敛手段，需要立即关闭时运行 `停止Sunshine面板.cmd`；
- 卸载会结束代理进程并清理 `%LOCALAPPDATA%\SunshinePanel` 与公共桌面快捷方式。

## 验证

1. 直接访问 `https://127.0.0.1:47990` 仍需登录（对照组）；
2. 访问 `http://127.0.0.1:47991` 首页与 API 均返回 200，无需登录；
3. POST 接口（PIN 提交等）通过 CSRF，不返回 403；
4. 空闲超时后进程退出、端口释放；
5. `netstat` 只监听 `127.0.0.1`，无新增防火墙规则。
