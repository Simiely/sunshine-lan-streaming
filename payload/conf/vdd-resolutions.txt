# 预置设备分辨率。安装时并入 C:\VirtualDisplayDriver\vdd_settings.xml。
#
# 为什么需要这个文件：
#   VDD 只能切到 xml 里声明过的模式。Sunshine 的 dd_resolution_option = auto
#   会按客户端请求改分辨率，请求到列表外的模式就静默失败，画面停在原分辨率
#   （表现为"手机上是 800x600 的小画面"），日志里还没有明显报错。
#
# 格式：设备名|宽x高|刷新率
#   - 名称可省略（那就只写 宽x高|刷新率）
#   - 刷新率可省略，默认 60
#   - 左边名称只用于安装时打印对照表；VDD 本身不支持给显示模式命名
#   - 本文件是唯一真相：写入时不在列表里的分辨率会被删除
#
# 【重要】第一条既是虚拟屏的初始分辨率，也是脚本识别虚拟屏的锚点：
#   脚本靠"虚拟屏当前分辨率 == xml 第一条"把它和物理屏区分开。
#   所以第一条必须选物理屏不会用到的分辨率。本机物理屏是 2560x1440，
#   用 1920x1080 做锚点是安全的；若哪天把物理屏改成 1080p，这里就要换一个。
#
# 注意：全局 g_refresh_rate 会被脚本收敛为只有 60，
#       想要更高刷新率必须在下面单独写。

# ---------- 设备原生分辨率 ----------
# 第一条 = 识别锚点，勿删、勿改顺序
Switch 底座|1920x1080|60
OPPO Find X9 Pro|2772x1272|60
iPhone 17 Pro Max|2868x1320|60
iPad Pro 12.9 英寸 M1|2732x2048|120
电视 4K|3840x2160|60

# ---------- Moonlight 通用档位 ----------
# 客户端分辨率是固定档位（720p/1080p/1440p/4K），缺模式时切分会静默失败。
# 1080p 已由 Switch 那条覆盖，这里只补 1440p。
2560x1440|60
